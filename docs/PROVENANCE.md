# Demo provenance

The bundled `examples/claude-structural.jsonl` is **derived structure, not a raw transcript**.

- Source: [Entire CLI `transcript/testdata/claude_full2.jsonl`](https://github.com/entireio/cli/blob/76f1b5129b974afdf8e59e4ae3755083c10ff8ff/transcript/testdata/claude_full2.jsonl).
- Revision: `76f1b5129b974afdf8e59e4ae3755083c10ff8ff`.
- Source SHA-256: `b06722789bf9131ede579896bd169731d7396c02749afbf7d725deb115794ebb`.
- Source size: 1,168,216 bytes; 349 nonempty JSONL records.
- License: MIT; retained in `examples/LICENSE-entire.txt`.
- Authenticity evidence: upstream [`prompts_test.go`](https://github.com/entireio/cli/blob/76f1b5129b974afdf8e59e4ae3755083c10ff8ff/cmd/entire/cli/agent/claudecode/prompts_test.go) explicitly describes this as a real Claude Code session. We rely on the maintainer's description; we did not independently witness the run.

The bundled projection is generated by `incidentlab.core.project` in this release: 31,230 bytes, SHA-256 `1d876458cfcd237202c0636a09b60f146c99cf697f4c1a3665f8a406181f780d`. Re-running that function on the fixed source must produce identical UTF-8 bytes.

The allowlist projection removes all original prose, arguments, outputs, paths, timestamps and IDs. It preserves 349 record discriminators, 92 tool calls, 92 tool results and five explicit `is_error` flags. Failure results occur at source lines **44, 45, 53, 313, 334**. These are tool failures, not proof that the complete task failed. In particular a cancelled sibling tool is not necessarily an independent root cause. The application deliberately does not infer root cause from hidden output prose.

To validate the chain yourself, download the publicly licensed source using the permalink above, verify its SHA-256, inspect locally, and create a projected bundle. The source is not included in this distribution. The bundled derived file retains the license notice; this is a permitted derivative, not a claim of authorship over the original session.
